# TANEM intake

Эта папка — единая точка входа для результата TANEM Exporter.

Для Яндекс Карт переносите результат экспортёра сюда без ручной перекладки данных:

```text
intake/
└── yandex/
    ├── business.json      # обязательно, основной машинный источник
    ├── business.txt       # необязательно, человекочитаемая копия
    ├── ПРОВЕРКА.html      # необязательно, только ручная сверка
    └── assets/            # реальные фотографии из карточки
```

Не добавляйте `export.log`, `debug/`, cookies, токены, ключи, session-файлы и любые секреты.

После загрузки ChatGPT/агент должен:
1. прочитать `business.json`;
2. при необходимости свериться с `business.txt` и `ПРОВЕРКА.html`;
3. просмотреть `assets/`;
4. заполнить `site-data.js` по `START_HERE.md`, `RULES.md` и `docs/FACTORY_GUIDE.md`;
5. разложить клиентские медиа по каноническим именам;
6. перевести сайт в `mode: 'production'` только после прохождения проверок.

Папка `intake/` не включается в GitHub Pages artifact и не является частью публичной страницы сайта.
