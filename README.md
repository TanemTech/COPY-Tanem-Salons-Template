# Only for Salons — эталонный шаблон

> **Обычный ChatGPT начинает с [`START_HERE.md`](START_HERE.md).** Там находится полный сценарий: исследование ссылок → один запрос недостающих данных → сборка → проверка.

Для Codex дополнительно существует [`AGENTS.md`](AGENTS.md), но обычный Chat не должен зависеть от его автоматической загрузки. Правила находятся в [`RULES.md`](RULES.md), производственный процесс — в [`docs/FACTORY_GUIDE.md`](docs/FACTORY_GUIDE.md), а готовый постоянный промпт проекта — в [`docs/PROJECT_PROMPT.md`](docs/PROJECT_PROMPT.md).

Пустой рабочий шаблон цифрового офиса салона красоты. Визуальная система, адаптивность и механики перенесены из утверждённой версии Boshki Project (`ichAEY/boshki-project`, commit `9d7708e`), а данные и медиа исходного салона удалены.

## Что сохранено

- отдельные desktop- и mobile-интерфейсы;
- региональные языковые наборы: RU/EN для России и RU/EN/HY для Армении;
- каталог услуг и категории;
- портфолио и полноэкранная галерея;
- страницы мастеров;
- карусель отзывов;
- контакты и окно выбора способа записи;
- адаптивное поведение и анимации исходного эталона.

## Что очищено

- название, описание, адрес, телефон и график;
- реальные услуги, цены, мастера и отзывы;
- ссылки на карты и мессенджеры;
- рейтинг и клиентские медиа.

Записи `Мастер N`, `Клиент N`, `SALON NAME` и SVG-заглушки в `site-data.js` нужны только для демонстрации механик и заменяются при заполнении шаблона. В production пустой `team[]` не создаёт выдуманных сотрудников: интерфейс автоматически сохраняет четыре нейтральные системные карточки «Мастер». Демонстрационные услуги не содержат цен, времени, описаний или вариантов.

## Локальный запуск

```bash
python3 -m http.server 4173
```

Откройте `http://localhost:4173`.

Основные файлы:

- `index.html` — загрузчик, выбор версии устройства и CSS;
- `site-data.js` — единственный источник данных салона, услуг, мастеров, отзывов, контактов и медиа;
- `site-runtime.js` — подстановка production-данных, графика, способов записи и необязательных разделов;
- `desktop.js` — логика компьютерной версии; её утверждённые стили в `desktop.css`;
- `mobile.js` — логика мобильной и touch-версии;
- `mobile.css` — базовые мобильные стили;
- `mobile-overrides.css` — итоговые мобильные переопределения, подключаемые **после** динамических языковых стилей;
- `logo-placeholder.svg` и `media-placeholder.svg` — нейтральные заглушки.

Клиентский адрес хранится в трёх полях: короткие `salon.city` и `salon.address` для интерфейса плюс полный проверенный `salon.fullAddress`. Для России обязательны Яндекс `mapUrl`/`mapEmbedUrl`, для других поддерживаемых стран — Google Maps. Карточка мессенджера показывается только при реальной ссылке.

Правила производства и медиа: [`RULES.md`](RULES.md). Пошаговая инструкция по созданию нового клиентского сайта: [`docs/FACTORY_GUIDE.md`](docs/FACTORY_GUIDE.md). Для нового клиента **скопируйте `site-data.blank.js` в `site-data.js`**: стартовый файл не содержит демонстрационных услуг, мастеров и отзывов. Заполните только реальные данные и медиа, установите `mode: 'production'`, затем запустите `node tests/validate-site-data.cjs --production`. `site-data.js` в самом шаблоне остаётся демонстрационным только для проверки утверждённого дизайна.


## Безопасная очистка и защита эталона

- Контрольная ветка до глубокой очистки: `baseline/pre-deep-clean-2026-09-28` (коммит `f9007f0`). Исходный утверждённый эталон услуг: `baseline/services-approved-v1-2026-09-28`.
- Для правок стилей редактируйте отдельные CSS-файлы, а не создавайте новые встроенные `style.textContent` поверх старых. Сохраняйте порядок: `mobile.css` → динамический `salon-mobile-i18n-style` → `mobile-overrides.css`.
- При изменениях CSS/JS обновляйте версии `?v=` в `index.html` и URL позднего CSS в `mobile.js`. В противном случае браузер может показать устаревший интерфейс.
- Перед публикацией запускайте `node tests/validate-site-data.cjs --production`, `node tests/check-factory-contract.cjs` и `node tests/check-template-regression.cjs`. Затем проверяйте GitHub Actions (Chromium, WebKit и production-сценарий). Главную ветку `main` обновлять только после успешных проверок.

### Очистка устаревших стилей (2026-09-29)

Из загружаемых CSS удалены только селекторы прежних версий разметки, которые больше не создаются `desktop.js`, `mobile.js`, `site-runtime.js` или `index.html`. Явный список удалённых хуков находится в `scripts/style-cleanup-config.cjs`; `node scripts/prune-dead-css.cjs --check` блокирует их случайное возвращение. Regression-тест по-прежнему сравнивает с замороженным эталоном все действующие селекторы, каскад карточек услуг и их разметку. Не добавляйте старый хук обратно в список активных компонентов: для нового элемента сначала удалите его из списка retired и подтвердите изменение полным браузерным regression-набором.

Для отдельных клиентских репозиториев используйте `docs/FACTORY_GUIDE.md`: GitHub Actions автоматически получают неизменяемый исходный эталон даже после копирования файлов без истории Git. Production CI проверяет реальные данные клиента и открывает сайт в Chromium и WebKit, а не сравнивает клиентские фотографии с демонстрационными.

## Нейтральная палитра v2 (2026-09-28)

Цвета утверждены для общего шаблона: основной фон `#FAF9F6`, вспомогательный `#F1ECE5`, карточки `#FFFFFF`, тёмные секции `#242424`, текст `#252525`. Основные кнопки `#252525` (hover `#424242`, active `#161616`), второстепенные `#EBE5DE` и контурные на прозрачном фоне. В тёмных разделах акцент `#F5F2ED`.

Вся цветовая надстройка находится отдельно в `salon-palette.css`. На ПК она загружается после `desktop.css`, на мобильной версии — после `mobile-overrides.css`. Это сохраняет эталонную вёрстку, карточки услуг, типографику и анимации. Историческая пиксельная проверка отключает только цветовую надстройку, затем дополнительно проверяет реальные цвета и hover в браузере на ПК и телефоне. При копировании шаблона в клиентский репозиторий обязательно включать `salon-palette.css`.

## Мобильные категории, галерея и вкладки мастера (2026-09-28)

Категории услуг всегда однострочные с полным текстом и нормальными отступами: все категории имеют естественную ширину и горизонтально прокручиваются при необходимости. Фон ленты галереи `#F1ECE5` совпадает с фоном самой галереи, без отдельной тени; шрифт кнопок категорий увеличен на 10% до 12,1 px. В карточке мастера горизонтальная лента показывает последнюю вкладку целиком. Подробности зафиксированы в `RULES.md` и `docs/SERVICES_STYLE_LOCK_V1.md`.

## Естественная ширина категорий услуг на мобильном (2026-09-29)

Вместо сетки для 1–4 категорий применены однострочные горизонтально прокручиваемые карточки с реальными размерами Esmeralda: высота 35 px, отступы по 15 px, зазор 8 px, Manrope 12,705 px (+10% к предыдущей версии, +21% относительно исходного размера Эсмеральды).
